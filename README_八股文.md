## 破题

夫刷机之道，贵在得门而入；锁钥之术，妙在借隙而行。

## 承题

盖 MediaTek 之邦，有 bl2_ext 之职，司 Preloader 之权，执 EL3 之柄。惜其校验不严，开门揖盗，遂成天下刷机者之坦途焉。

## 起讲

昔者 fenrir 启其端，今者 sprig 承其绪。以寸许之 payload，充 千钧之 bl2_ext；于三极之地，行四补丁之事：SBC 者，安全之锁也，破之；SLA 者，串行之契也，毁之；DAA 者，代理之验也，废之。三关既破，则未签之 DA 可入，任意之读写可施，内存之倾倒可行，岂不快哉？

## 入题

然则二端口之说，不可不辨。

## 起股

第一端口，如昙花一现，俄顷而没，是 Preloader 之旧影也；
第二端口，若明珠乍出，八息而存，是 payload 之新辉也。

## 中股

向者，注入既毕，刷之则黑，永为砖矣，非复人形。今者，吾等载原厂 bl2_ext 于复合镜像之中，握手既空，则 trampoline 应声而起，运神功，施妙法，复其本位，续其正轨，安卓欣欣然而起，如枯木逢春，死而复生。砖不砖者，惟在八息之间；机不机者，全凭一线之连。

## 后股

至若移植新机，则地址之秘，随固件而变；补丁之迹，因版本而移。欲效此法者，当自逆向其固件，细察其指令，勿以我之方，套彼之机，犹刻舟求剑也。补丁四穴，皆有验字之关，不中则止，宁缺毋滥，此全生之道也。

## 束股

嗟乎！刷机之术，博则博矣，险亦险焉。慎其行，守其法，存其回退之路，护其原厂之器，则虽砖而可活，虽险而无虞。故曰：刷机有路，回头是岸；备份不辍，砖尽还阳。
